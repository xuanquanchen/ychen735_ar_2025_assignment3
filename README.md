This repository contains programming solutions for Assignment 3

- Q3 – WebXR (Babylon.js)  
  Interactive AR scene using Babylon.js with hit-test and controller input.  


- Q4 – OpenGL Projection and Camera Coordinate Mapping
  Implementation of projection matrix for Q4e  

- Q5 – Phong Reflection Model in Babylon.js
  Code for Q5
  
## ▶️ How to Run

### Q3 and Q5 (Babylon.js)
1. Open `index.html` in a modern browser (e.g., Chrome), or you can use the github page using the location of the file (For example for question 3 you can go to [https://xuanquanchen.github.io/ychen735_ar_2025_assignment3/Question_3/index.html](https://xuanquanchen.github.io/ychen735_ar_2025_assignment3/Question_3/index.html))
2. For Q3, enable WebXR support for AR mode on supported devices (Meta Quest 3).  
3. Use the controller to spawn and move the model (Q3).

### Q4 (Python version)
Make sure you have the required libraries installed, then run:
Run:

python intro_to_ar_hw3_q4e.py
